# Fliperama do POO

Cópia do quiz gamificado para estudar para a Prova 1 de Programação Orientada a Objetos em Java.

- Original: https://lorenzoficher.github.io/fliperama-do-poo/ ([lorenzoficher/fliperama-do-poo](https://github.com/lorenzoficher/fliperama-do-poo)), por Lorenzo Ponsi Ficher
- 83 questões com explicação; modos Lista do professor, Questões extras, Maratona, Sobrevivência e Revisar erros
- Tudo num único `index.html`: basta abrir no navegador
